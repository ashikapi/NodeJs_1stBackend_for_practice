# NodeJs_1stBackend_for_practice

## 🚀 Setup

```bash
git clone https://github.com/ashikapi/NodeJs_1stBackend_for_practice.git
cd NodeJs_1stBackend_for_practice
npm install
npm run dev
npm run start
````

Open [http://localhost:5000/](http://localhost:3000/) to view it.

## 📦 Build

```bash
npm run build
```
